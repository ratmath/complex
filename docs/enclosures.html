Rectangles and discs

Most complex numbers worth computing are not rational. An enclosure is a set with rational data that is proven to contain the number: a rectangle with sides along the axes, or a disc. Arithmetic on enclosures gives enclosures of every possible result.

Rectangles

A Rect is a real interval for the real part and another for the imaginary part.

import { rect, Rect } from "@ratmath/complex";

rect([1, 2], [0, 1]);        // [1, 2] + i[0, 1]
rect("1 + i", "1/10");       // the square of half-width 1/10 around 1 + i
rect("3 - 4i");              // a single point

const r = rect("1 + i", "1/10");
String(r);                   // "1 + 1i ± 1e-1": the midpoint, then the half-size
String(r.center);            // "1 + i"
r.contains("21/20 + 19/20i");    // true
r.real;                      // a Core RationalInterval; r.imag too
r.corners();                 // four Complex values
r.split();                   // four quarters

The operations are add sub mul div inv neg conj scale pow, and hull, intersect, contains, intersects for sets. Each returns a rectangle containing z∘wz \circ wz∘w for every zzz in the first and www in the second:

Reading a printed rectangle

A point prints exactly. Anything wider prints its midpoint to the digits asked for and then ± the half-size, so 1.4686939399 + 2.2873552872i ± 1.7e-21 means both parts are within 1.7×10−211.7\times10^{-21}1.7×10−21 of an exact rational midpoint whose leading digits are shown. toString(40) shows forty digits; toJSON() gives the four exact corners.

Discs

A Disc is a rational centre and a rational radius.

import { disc } from "@ratmath/complex";

const d = disc("1 + i", "1/10");
String(d.mul(disc("2", "1/10")));   // "disc(2 + 2i, 0.35142135624)"
String(disc("2", 1).inv());         // "disc(2/3, 0.33333333333)": exactly centre 2/3, radius 1/3
disc(0, 1).contains("3/5 + 4/5i");  // true, decided exactly
d.toRect();  r.toDisc();            // each contains the other shape

Which to use

Rectangles fit the functions: eze^zez, sin⁡z\sin zsinz and log⁡z\log zlogz separate into real functions of xxx and yyy, so their images of a rectangle are easy to bound tightly. That is why the functions in this package return rectangles. Discs fit multiplication: multiplying by a number of modulus 1 turns a disc without growing it, while a rectangle must be redrawn around its turned self and grows by up to 2\sqrt22​ each time. The box at the end of this page shows a rectangle growing thousands of times over in twenty multiplications, while the disc grows only as much as twenty-one uncertain factors must.

Functions of an enclosure

Every function in Functions takes a rectangle or a disc as well as an exact number. The output then contains the value at every point of the input, so an uncertain measurement can be carried through a calculation and the uncertainty of the result read off at the end.
