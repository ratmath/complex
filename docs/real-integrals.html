Complex analysis

Real integrals by residues

Some integrals over the real line are easiest in the complex plane: close the path with a large semicircle, show the semicircle contributes nothing, and add up residues. Two families are done here from start to finish, with each step of the argument written out and the value proved.

import { realLineIntegral, trigIntegral } from "@ratmath/complex";

const r = realLineIntegral("1/(x^2 + 1)^2");
r.real;                    // an interval around π/2 = 1.5707963267948966, 2.7e-20 wide
r.steps;                   // the argument, as { title, detail }

realLineIntegral("x/(x^2 + 1)", { fourier: 2 }).sin;   // ∫ x sin 2x/(x² + 1) dx = π/e²

trigIntegral("1/(2 + cos(t))").real;                   // 2π/√3 = 3.62759872847

Rational functions over the whole line

Let f=P/Qf = P/Qf=P/Q with deg⁡Q≥deg⁡P+2\deg Q \ge \deg P + 2degQ≥degP+2 and no real root of QQQ. Integrate round the segment [−R,R][-R, R][−R,R] and the semicircle above it. On the semicircle ∣f(z)∣≤C/R2|f(z)| \le C/R^2∣f(z)∣≤C/R2, so that part is at most πC/R\pi C/RπC/R and vanishes as RRR grows. What is left is

∫−∞∞f(x) dx=2πi∑Im⁡zk>0Res⁡zkf. \int_{-\infty}^{\infty} f(x)\,dx = 2\pi i \sum_{\operatorname{Im} z_k > 0} \operatorname{Res}_{z_k} f. ∫−∞∞​f(x)dx=2πiImzk​>0∑​Reszk​​f.

The steps the function takes:

  1. The formula is turned into exact polynomials PPP and QQQ and common factors are cancelled, so a removable singularity on the real axis does no harm.
  2. The degrees are compared; if the integral does not converge the call is refused and says why.
  3. Every root of QQQ is found by zeros in a square that Cauchy's bound proves large enough, and the count is checked against the degree.
  4. Each root must be provably above or below the real axis. One that is on it, or too close to tell, is refused: the integral does not exist as it stands.
  5. At a simple pole the residue is P/Q′P/Q'P/Q′, evaluated on the root's enclosure. At a multiple pole it is a contour integral round a small circle.

Fourier integrals

With { fourier: a } the integrand is f(x)eiaxf(x)e^{iax}f(x)eiax. For a>0a > 0a>0 the factor eiaze^{iaz}eiaz decays in the upper half-plane, and Jordan's lemma makes the semicircle vanish as soon as deg⁡Q≥deg⁡P+1\deg Q \ge \deg P + 1degQ≥degP+1. For a<0a < 0a<0 the path closes below instead. When fff is real on the real axis the real and imaginary parts of the result are the cosine and sine integrals, returned as cos and sin.

Trigonometric integrals over a period

For a rational function RRR of cos⁡t\cos tcost and sin⁡t\sin tsint, put z=eitz = e^{it}z=eit. Then cos⁡t=(z+1/z)/2\cos t = (z + 1/z)/2cost=(z+1/z)/2, sin⁡t=(z−1/z)/(2i)\sin t = (z - 1/z)/(2i)sint=(z−1/z)/(2i), dt=dz/(iz)dt = dz/(iz)dt=dz/(iz), and as ttt runs from 0 to 2π2\pi2π the point zzz runs once round the unit circle:

∫02πR(cos⁡t,sin⁡t) dt=∮∣z∣=1g(z) dz=2πi∑∣zk∣<1Res⁡zkg. \int_0^{2\pi} R(\cos t, \sin t)\,dt = \oint_{|z|=1} g(z)\,dz = 2\pi i \sum_{|z_k| < 1} \operatorname{Res}_{z_k} g. ∫02π​R(cost,sint)dt=∮∣z∣=1​g(z)dz=2πi∣zk​∣<1∑​Reszk​​g.

trigIntegral makes the substitution, reduces ggg to a quotient of polynomials, and sums the residues at the poles proved to be inside the circle. cos(2t) and the like are understood. A pole on the circle means the integrand is unbounded, and is refused.

The formula's variable is x (or z) for the line and t (or theta, or x) for the circle; name another with variable. Coefficients must be exact, which here means rational numbers and i.
