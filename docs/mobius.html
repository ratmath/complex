Möbius maps

The maps z ↦ (az + b)/(cz + d) are the conformal bijections of the Riemann sphere. With complex rational coefficients they are exact: rational points go to rational points, circles to circles, and the cross-ratio of four points never changes.

const T = mobiusFrom([0, 1, infinity], ["i", 1, -1]);   // the one map sending three points to three
T.apply("1/2");                       // an exact complex rational
crossRatio(2, "i", 0, infinity);      // -2i
concyclic(1, "i", -1, "-i");          // true: the cross-ratio is real
mobius(1, 1, 1, 0).classify();        // "loxodromic"
circle(0, 1).map(cayley().inverse()); // the line y = 0, exactly

The maps

A Möbius map is given by a matrix (abcd)\begin{pmatrix} a & b \\ c & d\end{pmatrix}(ac​bd​) with ad−bc≠0ad - bc \ne 0ad−bc=0, and composing maps multiplies matrices. What kind of map

The number τ=(a+d)2/(ad−bc)\tau = (a + d)^2/(ad - bc)τ=(a+d)2/(ad−bc) does not change when the matrix is scaled or the map is conjugated, and it decides what the map does near its fixed points:

  • parabolic, τ = 4: one fixed point, like z ↦ z + 1;
  • elliptic, τ real in [0, 4): a rotation about two fixed points, like z ↦ e^{iθ}z;
  • hyperbolic, τ real and greater than 4: a stretch from one fixed point towards the other, like z ↦ 2z;
  • loxodromic, otherwise: a stretch and a turn together.

With rational coefficients τ is a complex rational and the test is exact. The fixed points solve cz2+(d−a)z−b=0cz^2 + (d - a)z - b = 0cz2+(d−a)z−b=0. When the square root of the discriminant is a complex rational they are exact; otherwise they come back as certified rectangles, such as the golden ratio for z ↦ 1 + 1/z.

Circles and lines

When A ≠ 0 it is the circle with centre −B/A-B/A−B/A and radius² (∣B∣2−AC)/A2(|B|^2 - AC)/A^2(∣B∣2−AC)/A2, and when A = 0 it is a line.
