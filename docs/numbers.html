Complex rationals

A complex rational is a+bia + bia+bi with aaa and bbb fractions. They are closed under the four operations, so arithmetic on them is exact, with no rounding anywhere.

Writing one

import { complex, Complex } from "@ratmath/complex";

complex("3 - 4i");               // from text
complex(3, -4);                  // from two parts, each anything Core reads
complex(["1/2", "0.#3"]);        // 1/2 + 1/3 i
complex("(1 + 2i)/(3 - i)");     // text may be an expression: 1/10 + 7/10i
complex("(1 + i)^8");            // 16
complex(0.1);                    // 1/10: a decimal number means the decimal it prints as

Text is exact arithmetic on numbers in Core's notation (1/2, 0.25, 0.#3 for a repeating decimal, 1..1/2 for a mixed number), the letter i, + - * /, ^ with a whole-number exponent, and parentheses. 3/4i reads as 34i\tfrac34 i43​i, the way it is written by hand.

Arithmetic

const z = complex("3 + 4i");
String(z.add("1 - i"));      // "4 + 3i"
String(z.mul("1/2 + i"));    // "-5/2 + 5i"
String(z.div("1 - 2i"));     // "-1 + 2i"
String(z.inv());             // "3/25 - 4/25i"
String(z.pow(-2));           // "-7/625 - 24/625i"
String(z.conj());            // "3 - 4i"
String(z.norm());            // "25": |z|², always rational
String(z.exactModulus());    // "5": |z| when it is rational, else null
z.equals("3 + 4i");          // true: equality is exact

Every method takes its argument in any of the forms complex reads. The parts are Core Rationals at z.re and z.im. Division by zero throws a ComplexError with code: "division-by-zero".

Why the norm and not the modulus

The modulus ∣z∣=a2+b2|z| = \sqrt{a^2 + b^2}∣z∣=a2+b2​ is usually irrational: ∣1+i∣=2|1 + i| = \sqrt2∣1+i∣=2​. Its square, the norm N(z)=zzˉ=a2+b2N(z) = z\bar z = a^2 + b^2N(z)=zzˉ=a2+b2, is always rational and is multiplicative, N(zw)=N(z)N(w)N(zw) = N(z)N(w)N(zw)=N(z)N(w). So the exact layer works with the norm, and the modulus is an enclosure (see Polar form) except when it happens to be rational, which is exactly when (a,b,∣z∣)(a, b, |z|)(a,b,∣z∣) is a rational Pythagorean triple.

Exact square roots

Writing w=x+iyw = x + iyw=x+iy with w2=a+biw^2 = a + biw2=a+bi gives x2=(∣z∣+a)/2x^2 = (|z| + a)/2x2=(∣z∣+a)/2 and y2=(∣z∣−a)/2y^2 = (|z| - a)/2y2=(∣z∣−a)/2, with the sign of yyy that of bbb. So z\sqrt zz​ is a complex rational exactly when ∣z∣|z|∣z∣ is rational and both of those are squares of rationals:

complex("3 + 4i").exactSqrt().map(String);    // ["2 + i", "-2 - i"]
complex("-5 - 12i").exactSqrt().map(String);  // ["2 - 3i", "-2 + 3i"]
complex("-4").exactSqrt().map(String);        // ["2i", "-2i"]
complex("2").exactSqrt();                     // null: use sqrt() for an enclosure

As a field

CQ is the field Q(i)\mathbb{Q}(i)Q(i) as a RatMath field object (add, mul, inv, zero, one and the rest), which is what linalg matrices and structures polynomials take when their entries are complex. Its sign is 0 for zero and 1 otherwise, because the complex numbers cannot be ordered: if iii were positive or negative, i2=−1i^2 = -1i2=−1 would be positive.
