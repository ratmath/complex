@ratmath/complex

Complex numbers, branches and contours, certified

Exact complex rationals, elementary functions that say which branch they took, and complex analysis with proofs: contour integrals, residues and zero counts enclosed in rectangles that are guaranteed to contain the truth. Quaternions and octonions live here too.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • Exact complex rationals, rectangles and discs as enclosures, polar form.
  • Elementary functions (exp, log, powers, roots, trigonometric) that report the branch used and when a cut is crossed.
  • Quaternions and octonions by the Cayley–Dickson construction, rotations, integer quaternions.
  • Complex Taylor models, contour integrals, the argument principle and isolation of zeros.
  • Residues, Laurent series, classification of singularities, real integrals by residues.
  • Möbius and conformal maps, with pictures through graphics.
  • The complex gamma and zeta functions.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
